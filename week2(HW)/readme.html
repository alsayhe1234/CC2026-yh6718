Process Drawing

For this assignment, I created a process drawing based on three simple shapes: square, circle, and line. I gave each shape its own rule. The square can scale to 0.5x, 1x, or 2x; the circle can move between the top, center, and bottom positions; and the line can rotate to 0, 45, or 90 degrees. I first explored these rules through a hand-drawn process and then translated them into p5.js using random selections. I also added random colors to create more variations each time the sketch is generated.
